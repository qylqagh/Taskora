\# Taskora — личный менеджер задач



Десктопная информационная система для управления личными задачами

(C# / Windows Forms / SQLite).



\## Возможности

\- CRUD задач: создание, просмотр, изменение, удаление с подтверждением

\- Поля задачи: название, описание, категория, приоритет, срок, статус

\- Поиск по названию, описанию и категории

\- Фильтры по статусу и категории, автосортировка по приоритету и сроку

\- Регистрация, вход, выход; роли: администратор и пользователь

\- Администратор управляет пользователями и видит все задачи



\## Технологии

\- C#, .NET 10, Windows Forms

\- SQLite (пакет Microsoft.Data.Sqlite)

\- Пароли — SHA-256, все запросы параметризованы (защита от SQL-инъекций)



\## Запуск из исходников

1\. Открыть `Taskora.sln` в Visual Studio 2022/2026.

2\. Дождаться восстановления пакетов NuGet (Microsoft.Data.Sqlite).

3\. Нажать F5 — база данных создастся автоматически.



\## Готовый дистрибутив

Папка `Taskora-v1.0` с `Taskora.exe`: Windows 10/11 x64, установка не требуется.



\## Демо-аккаунты

\- `admin / admin123` — администратор

\- `user1 / user1234` — пользователь



\## Структура проекта

\- `Модели/` — классы данных

\- `Формы/` — окна приложения и дизайн-система

\- `Логика/` — бизнес-логика, сервисы, валидация

\- `БазаДанных/` — инициализация SQLite и сессия пользователя
